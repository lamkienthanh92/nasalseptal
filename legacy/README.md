# Legacy

`react-schematic/` is an earlier React prototype (a schematic septum with an L-strut and graft patches drawn on a quadrilateral). It is kept for reference only. It is not part of the current app, which lives in `src/` and is built into `index.html`.

To run it: `cd legacy/react-schematic && npm install && npm start`. You can delete this folder if you do not need it.
